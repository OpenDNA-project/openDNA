# Test plan

What a scientist needs to trust OpenGenEdit. `[x]` = a test exists (where); `[ ]` = missing (what it must assert).
Rust tests live in `core/src/*.rs` (`cargo test`), Python in `tests/` (pytest). Quick in-app checks run from
Tools > Settings > Self-test (`app/selftest.py`, also run by `tests/test_selftest.py`); they are marked **(self-test)**.
Add new checks there when they are small and need no user files.

**`docs/TEST_CATALOGUE.md` is the companion to this file:** this one lists what *should* be covered, that one explains
in plain language what every existing test actually does and records the biological-accuracy review of the suite.
[`docs/test-report/`](test-report/README.md) lists the input and expected output of every test with its last result, and
[`docs/test-report/AUDIT.md`](test-report/AUDIT.md) the gaps that are still open.
